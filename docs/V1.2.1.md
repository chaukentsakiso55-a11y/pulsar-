# Pulsar AI v1.2.1 — Integrated Model Presets

Pulsar AI v1.2.1 adds a curated model-preset layer so multiple real model families can be connected without manually retyping provider JSON.

## Integrated presets

| Preset | Backend model | Engine | Intended tier |
|---|---|---|---|
| Qwen3 1.7B | `qwen3:1.7b` | Ollama | light |
| Llama 3.2 3B | `llama3.2:3b` | Ollama | light |
| DeepSeek-R1 1.5B | `deepseek-r1:1.5b` | Ollama | light |
| Gemma 3 1B | `gemma3:1b` | Ollama | very-light |
| Qwen3 8B | `qwen3:8b` | Ollama | medium |
| Qwen3 8B | `Qwen/Qwen3-8B` | vLLM | GPU server |

Run `PULSAR.bat` and choose **[15] Add integrated AI model preset**. The wizard can optionally call `ollama pull` for Ollama presets, updates `configs/providers.local.json`, and probes the local `/v1/models` endpoint.

Multiple presets may coexist. Pulsar Max automatically ranks enabled providers by quality, speed, cost, and reasoning capability, then uses the existing health-aware failover layer when a backend is unavailable.

## Security

The preset catalog contains no API keys or tokens. Local presets have empty `api_key_env` fields. Cloud providers remain available through the existing provider wizard, which stores secrets only in the Git-ignored local `.env`.

## Important limitation

The model weights are not bundled into the Pulsar ZIP. They are much larger than the application source and have their own licenses. Ollama/vLLM manages the actual model download/serving on the user's machine or server.
